# CLAUDE.md — test-review-dojo

テストを「書く側」の考え方から体系的に学ぶための学習リポジトリ。学習者はテストを書いた実務経験がない。

## 方針
- 穴探しのクイズではなく、専門的な考え方（原則・設計技法）を積み上げる構成にする
- 各章は `docs/NN-*.md`（解説）と `examples/chNN/`（動くサンプル）のセット
- 章は 1 つずつ追加し、README のロードマップの状態を更新する
- サンプルの「実験」結果は、実際にコードを変えて実行して確かめてから書く
- 説明は日本語。専門用語には初出で意味を添える
- 学習者の質問には、すぐに答えを出さず、まず該当する章の基準に立ち返らせる

## 技術
- TypeScript (strict) + Vitest、パッケージマネージャは pnpm
- `pnpm test` / `pnpm typecheck` が通る状態を保つ
